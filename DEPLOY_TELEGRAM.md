# Бесплатный пробный запуск внутри Telegram

Бот: **@abl_schedule_bot**. Приложение должно работать на интернет-сервере с HTTPS; окно на вашем Windows-компьютере для этого варианта больше не требуется. Отдельный домен покупать не нужно.

## 1. Подготовьте два значения

- **Токен бота**: в Telegram откройте проверенный @BotFather → `/mybots` → `@abl_schedule_bot` → **API Token**. Не публикуйте токен в чате или GitHub.
- **Ваш числовой Telegram ID**: его можно узнать, например, отправив `/start` в @userinfobot. Нужен ID пользователя, а не @имя. Этот ID получит доступ организатора.

## 2. Создайте аккаунт Render и подключите GitHub

Откройте [Render](https://dashboard.render.com/) и войдите через GitHub под аккаунтом с доступом к `AlexCoin/AblSchedule`. При запросе доступа можно выбрать только этот репозиторий.

Нажмите **New → Blueprint**, выберите репозиторий **AlexCoin/AblSchedule**, ветку **main**. Render прочитает файл `render.yaml`.

Альтернативная ссылка: [развернуть шаблон](https://render.com/deploy?repo=https://github.com/AlexCoin/AblSchedule).

## 3. Проверьте тарифы и введите параметры

Шаблон запрашивает:

- веб-сервис `abl-schedule` — **Free**;
- PostgreSQL `abl-schedule-db` — **Free**.

Перед подтверждением проверьте, что оба сервиса действительно бесплатные в вашем аккаунте. Доступность, сроки хранения и ограничения определяет Render. Если предлагается платный план, не подтверждайте его для этого пробного запуска.

В полях переменных задайте:

| Поле                 | Что ввести                                          |
| -------------------- | --------------------------------------------------- |
| `TELEGRAM_BOT_TOKEN` | Токен из BotFather, только в защищённом поле Render |
| `ADMIN_TELEGRAM_IDS` | Ваш числовой Telegram ID                            |

Имя `abl_schedule_bot`, ключ сессии, секрет webhook и подключение базы шаблон заполняет сам. **APP_URL вводить не нужно:** приложение использует адрес Render автоматически.

Нажмите кнопку создания/развёртывания Blueprint и дождитесь статуса **Live** у веб-сервиса. В Logs должны появиться сообщения о готовности Next.js и «Настройки сохранены для @abl_schedule_bot». Если токен или ID введены неверно, исправьте их в **Environment**, сохраните и перезапустите/переразверните сервис.

## 4. Откройте приложение в Telegram

1. Откройте [@abl_schedule_bot](https://t.me/abl_schedule_bot).
2. Нажмите **Запустить / Start**.
3. Нажмите **«🏀 Открыть расписание»** в сообщении либо **«Расписание»** в меню бота.
4. Приложение откроется внутри Telegram, вход выполнится автоматически.
5. У организатора появится раздел управления. Капитаны могут командой `/teams` выбрать несколько своих свободных команд; организатор может исправить привязки в справочнике.

У капитана без команды приложение предлагает выбрать её командой `/teams` и показывает его ID. Бот также отправляет ID при /start. Все участники должны предварительно нажать Start в боте, чтобы он мог отправлять им уведомления.

## Что нужно знать о пробном запуске

- Render может останавливать бесплатный сервис без активности. Первое открытие или ответ /start после паузы может задержаться; откройте веб-адрес сервиса из панели Render, дождитесь загрузки и повторите /start.
- Бесплатная база может иметь срок действия и другие ограничения. Посмотрите дату окончания в панели Render и не храните здесь единственную копию важных данных.
- В публичном Telegram-приложении `DEMO_MODE=false`: переключателей капитанов не будет. Для проверки используйте реальные Telegram-аккаунты и назначьте им команды.
- Начальные названия команд и пары — примеры. Измените их и создайте подходящий тур; локальная SQLite-демобаза с Windows автоматически на сервер не переносится.
- Перезапуск приложения не удаляет данные PostgreSQL. Удаление или истечение срока базы — отдельная операция провайдера.
- Можно пользоваться и обычным браузером по HTTPS-адресу Render. Публичное расписание видно без входа.

Развёртывание считается проверенным только после реального входа через вашего бота, согласования двумя аккаунтами и получения уведомления. До этого проверены только локальные тесты кода.

## Каталог Pale, Slow, Rook и Last

После обновления кода приложение автоматически импортирует 32 команды из присланной выгрузки страницы (по 8 на дивизион). В /teams они сгруппированы по дивизионам. Старые игры и привязки не удаляются. Чтобы составить реальное расписание, создайте новый тур с актуальными парами; импорт каталога не заменяет пары старого демонстрационного тура.

Blueprint содержит build-команду `npm ci --include=dev && npm run catalog:assets && npm run build`. Если сервис создан вручную или Render не применил изменение Blueprint, обновите **Settings → Build Command** на эту строку. Все 32 логотипа уже включены в репозиторий из новой пользовательской выгрузки. При сборке проверяется локальный кэш, скачивать их с CDN заново не требуется. При отсутствии локального файла остаётся официальная ссылка. Вручную заполнять справочник из 32 команд не требуется.
